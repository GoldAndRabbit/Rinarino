# romance_branch —— 分支恋爱

一个共同开场把人物一次性摆齐，然后玩家挑一个人走到底。别搞回合交叉，
一个下午的时间只够陪一个人，这个限制本身就是戏。

## 图的形状（硬要求）

```
开场 ──┬── A一 ── A二 ── A三 ── A结算 ──┬── A真结局
       │                               └── A擦肩
       ├── B一 ── B二 ── B三 ── B结算 ──┬── ...
       └── C一 ── C二 ── C三 ── C结算 ──┴── ...
```

- 角色 3 人，全部女性，年龄 / 职业 / 语速 / 说话长度必须明显不同
- 开场恰好 3 个选项，每个选项进一条线，并给对应角色 +1
- 每条线恰好 3 个结点，每个结点恰好 2 个选项
- 每条线总共要能拿到的好感上限是 4（开场 1 + 线上 3），阈值写 `>= 3`
- 每条线 2 个结局：真结局 / 擦肩结局。擦肩不能是惩罚，要是另一种真实

## 写法要求

- 每个结点先给 `# node:` 一个两字短名（如「昭二」），分支图上要放得下
- 选项文本是**玩家要说的话或要做的事**，不是"选项A"这种标签
- 选项之间必须真的分岔：一个推进关系，一个后撤一步，不能两个都是同意
- 台词里不要写内心独白。人物的状态从她做什么、停在哪儿看出来
- 结局要落在一个具体的物件上（一张照片、一面墙、一本书），不要落在总结句上

## 变量

每个角色一个 `VAR <key> = 0`，key 用角色的拼音缩写，和 cast.json 的 key 对齐。
