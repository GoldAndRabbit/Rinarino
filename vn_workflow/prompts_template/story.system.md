## 语法（这是一个受限子集，写出范围就编译不过）

```
# title: 作品名

VAR key = 0                      // 变量只能声明在第一个结点之前，值只能是整数

=== knot_id ===                  // 结点，id 用小写英文和下划线
# node: 短名                      // 分支图上的名字，最多 {{node_label_max}} 个字
# bg: bg_xxx                     // 进场指令，id 自拟但必须全篇一致
# cg: cg_xxx                     // 事件 CG，设了之后本结点不叠立绘
# sprite: key:表情, key2:表情      // 台上有谁、什么表情
# amb: amb_xxx                   // 环境声
# music: bgm_xxx                 // BGM
角色名: 台词                       // 角色名必须和 cast 里的名字逐字一致
不带前缀的行是旁白
~ key += 1                       // 赋值，只有 = += -=
{key >= 3: -> other_knot}        // 条件跳转，必须写在选项前面
* [选项文本]                       // 选项
    ~ key += 1                   // 选项体：缩进 4 空格，可含台词和赋值
    -> next_knot                 // 选项必须有落点
-> END                           // 没有选项的结点用直接跳转；结局用 -> END
```

## 硬约束（编译器会逐条判，违反就会被打回来重写）

1. 每个有选项的结点，选项数 >= {{min_choices}}
2. 所有 `->` 的落点必须是已定义的结点 id 或 END
3. 从第一个结点必须走得到每一个结点，不能有孤岛
4. 不能出现「没有选项的结点互相跳转」构成的环
5. 至少 {{min_endings}} 个结局（`-> END`）
6. 每个 VAR 都要至少被一个条件读过，也至少被一个选项改过
